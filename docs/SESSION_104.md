# Session 104: shared-world fiscal forecast

## Delivered

- Shared-world budget forecasts and comparisons now run on a validated, detached copy of the full experimental registry, advancing both countries and existing bilateral talks and agreements. Fiscal totals use the simulated ledger, including one-time cooperation fees and year-end rollover.
- Fiscal proposal validation is shared with the single-country forecast. Tax changes, total-budget resets and selected-category proposals apply only to the copied controlled country; invalid or ambiguous requests return no forecast.
- The interface identifies whether it is using the shared or single-country model. Forecasts are marked stale when the world or bilateral state changes. No live country, relationship, agreement or save is changed by forecasting.

## Validation and limitations

- Automated checks compare a projected 60-day tax and category proposal with an independently advanced shared world, including a cooperation fee across a calendar year boundary; they also verify live-state isolation, invalid requests, UI availability and invalidation.
- Forecasts use the existing fictional deterministic rules and current talks, not realistic diplomacy, random shocks, future decisions or other unmodeled events. The two-country forecast has not been benchmarked on the deferred low-end target hardware.
