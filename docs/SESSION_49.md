# Session 49: structured event history

Events now retain a category, calendar date and display text alongside the existing newest-first text history; both are capped at 200. Categories cover finance, policy, institutions, diplomacy, elections, scenario and general events. The History tab can filter them, and the API returns copies. Save version 13 validates consistency between structured and displayed records; versions 1–12 migrate their existing text as legacy records with unknown structured dates/categories rather than inventing metadata. Tests cover filtering, copies, bounded history, save/load, malformed records, legacy migration and deterministic replay. Event payloads do not yet contain structured actors, causal inputs or localized message keys; this is not event sourcing or a full audit log.
