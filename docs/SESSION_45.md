# Session 45: integrated policy reliability

Forecast and policy-comparison outputs now visibly mark themselves out of date after a world refresh; editing comparison inputs also marks the comparison out of date. Users explicitly rerun them. This conservative approach may mark a forecast stale after a refresh that did not change simulation state, but avoids treating old estimates as current.

An integrated 365-day test starts a cooperation negotiation and reporting directive together, checks agreement and court timing, saves during implementation, reloads, compares continued state and forecast with actual outcomes, checks public services and approval, then revokes the directive and terminates the agreement. The existing four-year deficit test still exercises leap year, election and accounting. During testing, restored diplomatic counters were found to be floating-point values from JSON; import now normalizes validated day counters to integers and relations to floats. Simulation, UI and integration tests pass locally; hosted CI is the separate GitHub verification record. These tests support consistency, not real-world accuracy, completeness, visual usability or performance at world scale.
