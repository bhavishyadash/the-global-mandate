# Session 50: package and startup checks

Added a Windows development export preset that explicitly includes scenario JSON, plus `tools/check_export.py`. The check creates a temporary resource pack and runs a scenario-and-tick smoke script from an empty working directory, so project files cannot conceal a missing packaged scenario; it rejects Godot errors as well as nonzero exit codes and missing completion markers. The check was run locally with Godot 4.7.2 and added to CI. Editor-generated Godot UID and import metadata are tracked to keep resource identities stable. The local sandbox could not write normal Godot editor settings, so package verification was rerun with normal editor-directory access. No matching Windows export templates were present; a standalone executable, graphical rendering and target-platform installation remain unverified.
