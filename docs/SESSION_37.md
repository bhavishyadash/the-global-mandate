# Session 37: fiscal forecast

Added an on-demand 365-day forecast using an independent copy of the current world. It advances the same daily rules, including changes in interest, policy implementation, services and scheduled elections, and reports ending cash, debt, approval, revenue and costs plus the first day cash is exhausted. The model accepts horizons of 1–366 days; the interface uses 365. The forecast does not mutate the live world or write saves and must be rerun after changes. It assumes no further player decisions or outside shocks and depends entirely on fictional prototype rules; it is not an economic prediction. Headless checks compare the forecast with actual simulated results, verify non-mutation, invalid horizons and deficit behavior, and exercise the UI.
