# Session 57: startup window usability

The initial standalone build opened in a very small window on the current Windows machine. The project now starts maximized while retaining normal window controls. A fresh Windows build was started graphically: it opened maximized, restored to a window and could be maximized again. The five Godot suites and headless build startup passed. This is a targeted usability fix, not proof of accessibility, 720p compatibility, multi-monitor behavior or low-end performance; the restored window remained small on this machine.
